# Music Glass 統合ベータ

ユーザー提供の Music-Glass-YouTube-Music-v1.2.7.zip を統合。元ファイルにライセンス表記はありません。公開配布時は提供元の利用条件を別途確認してください。

設定キーを musicGlassEnabled / musicGlassArtwork / musicGlassIntensity に分離しました。テーマは初期状態ON。ポップアップの「背景・テーマの設定を開く」からOFFにもできます。テーマ設定はこの端末のローカル保存で、既存の歌詞バックアップには含みません。

通常版と同じ拡張IDを維持しているため、同時利用ではなく、バックアップ後に読み込み済みフォルダーを差し替えて試してください。単体のMusic Glass拡張は二重適用を避けるためOFFにしてください。通常版へ戻す場合は通常版のファイルへ戻して再読み込みしてください。

実機での表示は未確認です。
