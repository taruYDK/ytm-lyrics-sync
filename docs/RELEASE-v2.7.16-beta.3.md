プレイリスト画面の背景に横帯状の段差が出る問題への対策を追加しました。

## 🔧 更新内容
- ページ内の装飾用背景を透明にし、共通の背景が一続きに見えるよう調整しました。

## 📦 更新方法
1. 添付のZIPをダウンロードして解凍します。
2. 念のため、保存データをバックアップします。
3. 使用中の拡張機能フォルダーへ上書きします。
4. 拡張機能とYouTube Musicを再読み込みします。

※ 保存データを維持するため、更新時に拡張機能を削除しないでください。

## 🧪 ベータ版について
試用版のため、画面サイズによって表示が崩れる場合があります。単体のMusic Glass拡張を利用中の場合はOFFにしてください。テーマ設定は歌詞バックアップには含まれません。
