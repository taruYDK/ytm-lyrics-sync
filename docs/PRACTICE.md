# v2.8.0 新機能の使い方

歌詞タブの「その他」から開きます。曲別の表示設定・全画面歌詞・ローマ字を利用できます。

## 曲ごとの表示設定

「この曲の表示設定」で文字サイズ、日本語ふりがな、英語カタカナ読み、ローマ字を変更すると自動保存されます。保存ボタンを押す必要はありません。文字サイズは入力の確定時に保存します。別の曲へ移ると、その曲の設定、またはポップアップの共通設定に切り替わります。「共通設定に戻す」で曲別設定を解除できます。ローマ字は初期状態ではOFFです。

## 全画面歌詞ビュー

「全画面歌詞ビュー」で大きな歌詞を表示します。Music Glassの背景を利用し、OFFの場合も読み込み済みのジャケット画像を背景に使います。画像がまだ取得できないときは暗い背景を使います。原文、ふりがな、ローマ字を表示し、現在行を強調します。行を押すとその位置へ移動できます。通常表示と同じ単語・ふりがなの追跡と追跡位置を反映します。追跡をOFFにすると全画面の追跡も停止します。手動スクロール中は指定した待ち時間後に追跡に戻ります。「再生画面のスクロールバーを隠す」設定も全画面に反映されます。閉じるボタンは最初の3秒だけ表示し、その後は右上へカーソルを入れると表示します。キーボードのTabでもボタンに移動できます。「全画面を閉じる」またはEscで戻ります。ブラウザーが全画面を許可しない場合はウィンドウ内に表示します。

## ローマ字

「この曲の表示設定」で「ローマ字を表示」をONにします。内蔵の日本語辞書の読みからローマ字を作成します。辞書の初回読み込みには時間がかかる場合があります。読みの曖昧な漢字や固有名詞では誤りが出る場合があります。長音は母音を重ねて表記します。手動ふりがな編集とは独立した自動読みです。

## 保存と更新

曲別の表示設定は、この端末の拡張機能ストレージに保存します。既存のバックアップ・復元と保存済み曲一覧にも含めます。

更新前にバックアップしてください。解凍した内容を使用中の拡張機能フォルダーへ上書きし、拡張機能とYouTube Musicを再読み込みします。保存データを残すため拡張機能を削除しないでください。同じ拡張機能IDを使うため、正式版と別フォルダーから同時に読み込む用途ではありません。

## 確認範囲

自動テストと、ローカルのブラウザー検証画面で操作・狭い画面の表示を確認しています。YouTube Musicでの長時間再生、曲切り替えを含む利用確認は別途必要です。
