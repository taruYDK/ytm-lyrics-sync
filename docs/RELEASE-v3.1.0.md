# v3.1.0

## 歌詞追跡と表示の改善

- 一時停止中や歌詞タブを開いていない間の歌詞更新処理を軽くしました。
- 停止中のシークや再生再開時に歌詞の位置を更新します。
- 歌詞タブを開き直した直後に、不要な自動再同期が起きる問題を修正しました。
- 歌詞の検索中・未取得時の表示監視を絞りました。

## 読み仮名と内部処理

- 英語の読み仮名は、曲に必要な単語の読みだけをタブへ渡します。
- 表示設定や未使用コードを整理し、配布物に含めるファイルを見直しました。

## 更新方法

1. 設定画面の「データ管理」からバックアップを保存します。
2. 配布ZIPを解凍し、読み込み済みの拡張機能フォルダーへ上書きします。
3. 拡張機能の管理画面とYouTube Musicを再読み込みします。

保存データを維持するため、更新時に拡張機能を削除しないでください。
