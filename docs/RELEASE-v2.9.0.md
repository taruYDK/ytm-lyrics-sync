## v2.9.0 正式版

設定画面とMusic Glassの操作性、歌詞追従を改善した正式版です。

### 変更内容

- 設定画面の項目を整理し、目的の設定を探しやすくしました。
- 再生バーの角丸・開閉位置調整をON/OFFで切り替えられるようにしました。初期値はONで、Music GlassがONのときに適用されます。
- 再生バーの表示、タブ・操作ボタンのホバー表示、左メニューとヘッダーの境界線を調整しました。
- 歌詞パネルのタブ・取得状態・ボタン・歌詞をまとめて上へ移動し、上側の余白を縮めました。移動量は画面幅と余白に応じて最大48pxです。
- ジャケットのサイズはYouTube Music標準のレイアウトに任せています。
- メイン画面の追従スクロールを短いアニメーションに変更し、単語追跡で重複するDOM更新を減らしました。手動スクロールと動きを減らす設定も尊重します。
- 歌詞欄の左右位置と横スクロールを調整しました。歌詞のフォント設定は変更していません。
- 未使用の試験用ファイルと旧版の説明書を配布物から除外しました。

### 更新方法

1. 保存データをバックアップします。
2. 配布ZIPを解凍し、使用中の拡張機能フォルダーへ上書きします。
3. 拡張機能管理画面で再読み込みし、YouTube Musicのページも再読み込みします。

拡張機能を削除する必要はありません。保存済みデータのキーは変更していません。

### 確認範囲

ソースと生成物の一致、リポジトリの自動テスト、ローカルの表示・設定切替の検証を行っています。自動テストだけで実際のYouTube Musicの表示や外部APIを保証するものではありません。極端な画面比率や高倍率での開閉境界、練習表示と通常表示の追従の体感差は実機確認が必要です。
