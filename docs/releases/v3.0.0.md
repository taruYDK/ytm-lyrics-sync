# v3.0.0

## 更新内容

- 歌詞の追従スクロールを素早くし、ジャケット色の読み取り設定を調整。

- ジャケットの強調色取得と画像が取得できない場合の背景表示を改善。
- 歌詞拡大時の余白、曲切り替え後のフェード処理、案内の幅を調整。

- 再生画面の開閉アニメーションとON/OFF設定を追加。
- 歌詞位置、検索・未取得時の表示、外部歌詞画面のスクロールを調整。
- Spaceキーの再生操作を切り替え可能にし、入力欄や同期歌詞作成モードに配慮。
- 歌詞の現在行の強調、追従スクロールや曲切り替え時の表示を調整。
- 間奏の点表示は含まれません。

## 更新方法

1. 念のためポップアップの「データ管理」からバックアップを保存します。
2. 配布ZIPを解凍し、現在読み込んでいる拡張機能フォルダーへ上書きします。
3. 拡張機能の管理画面とYouTube Musicのタブを再読み込みします。

保存データを維持するため、更新時に拡張機能を削除しないでください。
