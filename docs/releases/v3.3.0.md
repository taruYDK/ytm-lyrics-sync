## v3.3.0 正式版

YouTube Musicの画面を、Mac版ミュージックのような見た目と操作に変えられるようになりました。

## 🍎 Mac版ミュージック風の画面

- YouTube Musicの上のバー・左のメニュー・再生バーを、Mac版ミュージックのようなサイドバーと上部の再生コントロールに置き換えます。
- 設定の「背景」→「Mac 版ミュージック風の画面」でON/OFFできます（初期値はON）。動くジャケット背景、サイドバーの自動非表示、アルバムの「再生」「シャッフル」ボタンも個別に切り替えられます。
- サイドバーはふだん隠れていて、マウスを窓の左端に寄せると出ます。
- 長い曲名やアーティスト名は、マウスを乗せると横に流れて全部読めます。

## 🎵 再生中の画面と歌詞

- 再生中の画面が窓いっぱいに広がり、ジャケットのぼかしがゆっくり動く背景の上に表示されます。
- 「次のコンテンツ」で2.5秒間操作しないと、自動で歌詞へ移ります（タブのガラスの玉をつかんでいる間は移りません）。
- 右側に歌詞パネルと「次に再生」（履歴・自動再生つき）を開けます。ミニプレーヤーにも対応しました。
- 歌詞の一節を、ジャケット入りのカード画像にして共有できます。
- 全画面歌詞は、左にジャケット・再生位置・再生ボタン・音量を並べるMac風のレイアウトになり、しばらく操作しないと操作部分が消えます。

## ⌨️ ショートカット

- Ctrl（Macは⌘）＋ →／← で次へ・前へ、↑／↓ で音量、F で検索、Shift＋L で歌詞、Shift＋U で次に再生、Shift＋P でミニプレーヤーを開きます。

## 🎨 見た目

- アルバム・プレイリスト・アーティスト・検索・ライブラリのページ、曲メニュー・並べ替えメニューをMacに近い見た目にそろえました。
- 設定画面とデータ管理画面を、Macのシステム設定のような見た目にしました。
- 再生中の画面のコメント欄は初期設定で隠れます（設定の「コメント欄を表示」で戻せます）。

## 🛠️ 動作の改善

- 曲を変えたあとや再生中に、画面の動き・スクロール・タブの切り替えが重くなる問題を直しました。
- 設定メニューの「診断情報」に、重い場面の原因を調べる項目を追加しました（診断情報を開いている間だけ計測します）。

## 📦 更新方法

1. 添付のZIPをダウンロードして解凍します。
2. 設定画面の「データ管理」からバックアップを保存します。
3. 使用中の拡張機能フォルダーへ上書きします。
4. 拡張機能の管理画面で拡張機能を再読み込みし、YouTube Musicも再読み込みします。

※ 保存データを維持するため、更新時に拡張機能を削除しないでください。
