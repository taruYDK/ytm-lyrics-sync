# v3.2.0

- 設定を6カテゴリに分け、歌詞の「その他」メニューを用途別に整理しました。
- 歌詞の提供元を表示します。歌詞が見つからない場合は、その場で歌詞を追加したり別の条件で検索したりできます。
- 全画面歌詞の文字サイズを A− / A+ で調整できます。ふりがな編集は入力とプレビューを並べ、少ないスクロールで操作できるようにしました。
- 全画面の開閉、曲を切り替えたときのジャケットと背景、歌詞行を選んだときの演出を調整しました。
- 一時停止中の現在行表示、英語LRCの空白と末尾の単語、別タブでのふりがな編集の上書きを修正しました。

## 更新方法

1. 拡張機能の「データ管理」でバックアップを保存します。
2. 配布ZIPを解凍し、読み込み済みの拡張機能フォルダーに上書きします。
3. 拡張機能の管理画面で再読み込みし、YouTube Musicを開き直します。
