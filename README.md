#YT Music 歌詞シンクロ v2.2.2

YouTube Music の歌詞タブに、外部から取得した同期歌詞や、自分で追加した同期歌詞を表示する非公式の Chromium 拡張機能です。

Microsoft Edge / Google Chrome に対応しています。

[!NOTE]
このプロジェクトは、YouTube、Google、Microsoft Edge、および各歌詞提供元とは関係のない非公式プロジェクトです。

最新版をダウンロード

GitHub の Releases から最新版の ZIP をダウンロードしてください。

⸻

v2.2.2 の更新内容

※ v2.2.1 の変更内容を含みます。

標準歌詞がない曲でも外部歌詞を表示

YouTube Music 標準の歌詞タブが無効になっている曲でも、「歌詞」から外部歌詞の表示・検索画面を開けるようになりました。

外部提供元にも歌詞がない場合は、以下の機能を利用できます。

* 手動検索
* ローカル歌詞の追加
* 同期歌詞の作成

※ スマホ版 YouTube Music の歌詞を直接取得する機能ではありません。

YouTube Music に馴染む表示へ改善

外部歌詞画面の固定背景を廃止し、YouTube Music 側の

* 背景
* タブの書体
* 文字サイズ

などに馴染む表示へ変更しました。

外部歌詞画面を閉じやすく改善

以下の操作で外部歌詞画面を閉じられます。

* 「次のコンテンツ」へ切り替え
* 「コメント」へ切り替え
* 「関連コンテンツ」へ切り替え
* Esc キーを押す

更新時の注意

更新前に、設定のバックアップを保存することをおすすめします。

既存の拡張機能を削除せず、現在読み込んでいる拡張機能フォルダーへ新版のファイルを上書きしてください。

更新後は、

1. 拡張機能を再読み込み
2. 開いている YouTube Music のタブを再読み込み

してください。

主な機能

同期歌詞の自動取得

複数の外部歌詞提供元から同期歌詞を検索し、YouTube Music の歌詞タブへ表示します。

対応する提供元は設定から有効・無効や優先順位を変更できます。

* Better Lyrics
* LRCLIB
* Unison
* BiniLyrics
* Karalyr

歌詞候補

「歌詞候補」から、取得した歌詞を

* 提供元
* 同期精度
* 行数

などを確認しながら選択できます。

候補には自動計算したおすすめ度も表示されます。

おすすめ度は同期精度、曲の言語との一致、提供元の優先順位、歌詞行数などから計算したもので、ユーザー投票や外部評価ではありません。

曲ごとの歌詞固定

歌詞候補にある 「📌 この歌詞を固定」 を押すと、その歌詞を動画 ID ごとに保存できます。

次回以降は通常キャッシュやネット検索より先に固定した歌詞を表示します。

固定を解除すると、通常の候補検索へ戻ります。

ローカル歌詞

「歌詞を追加」から、

* LRC を直接貼り付ける
* .lrc ファイルを読み込む

ことができます。

保存したローカル歌詞は動画 ID ごとに端末内へ保存され、すべての外部提供元より優先して表示されます。

同期歌詞作成モード

時刻情報のない歌詞から、自分で同期歌詞を作成できます。

歌詞を1行ずつ貼り付け、曲を再生しながら歌い始めのタイミングで 「この行を記録して次へ」 を押すことで LRC の時刻を記録します。

以下の操作にも対応しています。

* 1行戻す
* 記録をやり直す
* 曲の先頭へ戻る

前の行より前の時刻を記録した場合や、作成途中で別の曲へ切り替わった場合は誤保存しません。

歌詞編集

現在表示している歌詞の文章を書き換えられます。

各行のタイミングは維持され、変更した行のみ単語・音節同期から行同期へ切り替わります。

また、不要な歌詞行を選択して表示から削除することもできます。

編集内容は動画 ID と歌詞候補ごとに保存され、バックアップ／復元の対象になります。

タイミング補正

曲の好きな再生位置へ補正ポイントを追加できます。

各ポイントは、

* ±0.1秒
* ±0.5秒
* スライダー

で調整できます。

補正範囲は ±20秒 です。

複数の補正ポイントを設定した場合、ポイント間の補正量は滑らかに変化します。

最後に追加したポイント以降は、そのポイントの補正値を維持します。

位置によって歌詞がずれる場合

1. ずれが気になる位置まで曲を再生
2. 下部プレイヤーの「歌詞 ±0.0秒」を開く
3. 「現在位置に補正ポイントを追加」を押す
4. 補正値を調整
5. 必要に応じて別の位置にもポイントを追加

＋ で歌詞が早く、－ で遅く表示されます。

LRC 保存

現在表示している歌詞を、通常の行同期 LRC として保存できます。

保存済みの

* 歌詞の書き換え
* 行削除

も反映されます。

曲ごとのタイミング補正を LRC に反映するかどうかも選択できます。

LRC 保存時の注意

* 単語・音節単位の同期情報は含まれません。
* タイミング補正の反映は初期状態では OFF です。
* 補正を反映した LRC を同じ曲へ再登録する場合は、二重補正を防ぐため曲の補正を 0 に戻してください。
* 同期歌詞作成モードの未保存の下書きは、先に保存してください。
* LRC は端末内で生成され、LRCLIB などへ直接投稿されることはありません。
* 公開・共有する場合は歌詞の権利に注意してください。

診断情報

「その他 → 診断情報」から、現在の状態を確認できます。

主に以下の情報を確認・コピーできます。

* 拡張機能のバージョン
* 曲 ID
* 提供元
* 同期方式
* 候補数
* 補正ポイント数
* プレイヤー時刻の取得元

診断情報には、歌詞本文や認証情報は含まれません。

不具合報告時に利用できます。

⸻

歌詞の優先順位

歌詞は以下の順番で使用されます。

ローカル歌詞 → 固定した歌詞 → 通常キャッシュ → ネット検索

ローカル歌詞と固定歌詞は件数による自動削除を行いません。

インストール

Microsoft Edge

1. Releases から最新版の ZIP をダウンロード
2. ZIP を展開
3. edge://extensions を開く
4. 「開発者モード」を ON
5. 「展開して読み込み」を押す
6. manifest.json があるフォルダーを選択
7. YouTube Music を再読み込み

Google Chrome

1. Releases から最新版の ZIP をダウンロード
2. ZIP を展開
3. chrome://extensions を開く
4. 「デベロッパーモード」を ON
5. 「パッケージ化されていない拡張機能を読み込む」を押す
6. manifest.json があるフォルダーを選択
7. YouTube Music を再読み込み

⸻

更新方法

v1.9.7 以降から更新する場合

保存データを維持するため、拡張機能を削除せずに更新してください。

1. ポップアップの「データ保護」からバックアップ JSON を作成
2. 新しい ZIP を展開
3. 現在 Edge / Chrome で読み込んでいる拡張機能フォルダーへ、新版ファイルをすべて上書き
4. edge://extensions または chrome://extensions を開く
5. 拡張機能の「再読み込み」を押す
6. 開いている YouTube Music の全タブを再読み込み

固定の拡張機能 ID と同じ保存キーを維持しているため、この方法なら以下のデータを引き継げます。

* タイミング補正
* 手動検索条件
* 歌詞編集
* 固定候補
* ローカル歌詞
* 表示設定

[!WARNING]
拡張機能を「削除」すると、ブラウザ側でローカルデータが削除される場合があります。更新時は削除せず、既存フォルダーへ上書きしてください。

⸻

バックアップ・データ管理

ポップアップの「データ保護」から、保存データを JSON ファイルへバックアップ／復元できます。

バックアップ対象は、

* 表示設定
* 曲ごとのタイミング補正
* 手動検索条件
* 歌詞編集
* 固定候補
* ローカル歌詞

です。

以下はバックアップに含まれません。

* 通常取得した歌詞キャッシュ
* Better Lyrics の認証情報

保存データ管理

「バックアップ・復元・管理を開く」から、

* 曲名
* アーティスト
* 曲 ID

で保存データを検索できます。

不要な曲のデータも削除できます。

削除対象は、

* タイミング補正
* 歌詞編集
* 固定歌詞
* ローカル歌詞
* 手動検索条件

です。

表示設定と通常歌詞キャッシュは残ります。

[!CAUTION]
削除したデータを復元するには、削除前に作成したバックアップが必要です。

⸻

その他メニュー

歌詞上部は、

* 歌詞候補
* その他

の2つに整理されています。

「その他」から以下の機能を利用できます。

* 手動検索
* 歌詞編集
* 歌詞を追加
* LRC 保存
* 診断情報

メニューは、

* 同じボタンをもう一度押す
* メニューの外側をクリック
* Esc キーを押す

ことで閉じられます。

⸻

自動歌詞表示

「無操作時に歌詞を自動表示」を ON にすると、「次のコンテンツ」が表示されたあと、約1.9秒操作がなければ歌詞タブへ自動的に移動します。

待機開始後にクリックやスクロールを行った場合、その曲では自動移動をキャンセルします。

プライバシー

歌詞を検索するため、以下の情報を有効にした歌詞提供元へ送信します。

* 曲名
* アーティスト名
* アルバム名
* 再生時間
* 動画 ID

自分で追加したローカル歌詞や、書き換えた歌詞本文は外部へ送信しません。

詳細は PRIVACY.md を参照してください。

開発

v2.2.0 から、content.js を直接編集する構成から、機能別ソースをビルドする構成へ変更しました。

構成

* src/content/ — 16個の機能別ソース
* src/core/ — タイミング補間・LRC 書き出しなどの ES Modules
* tests/ — ユニットテスト
* content.js — 配布用ビルド生成物

バックグラウンド通信で追加できるヘッダーは Content-Type のみに制限し、現在使用している JSON・フォーム形式だけを許可しています。

送信元の拡張機能 ID も確認します。

テスト

以下のテストを追加しています。

* タイミング計算
* LRC 出力
* ヘッダー制限
* 保存競合
* ビルド結果一致

ZIP にはソース、ビルドスクリプト、テストも含まれています。

開発手順は DEVELOPMENT.md を参照してください。

Node.js 20 以降で以下を実行できます。

npm run build

npm test

外部パッケージのインストールは不要です。

拡張機能を使用するだけなら Node.js は必要ありません。
