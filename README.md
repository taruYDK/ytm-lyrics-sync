# YT Music 歌詞シンクロ

YouTube Musicで、曲に合わせて流れる歌詞を。

外部サービスの同期歌詞や、自分で追加した歌詞を、YouTube Musicの歌詞タブに表示する非公式のブラウザー拡張機能です。

**対応ブラウザー：Microsoft Edge / Google Chrome（PC版）**  
**バージョン：v2.3.2**

[最新版をダウンロード](https://github.com/taruYDK/ytm-lyrics-sync/releases/latest) · [不具合報告・機能の要望](https://github.com/taruYDK/ytm-lyrics-sync/issues)

> [!NOTE]
> YouTube、Google、Microsoft、および各歌詞提供元とは関係のない非公式プロジェクトです。

## 主な機能

- **同期歌詞の表示**  
  複数の外部提供元から歌詞を検索。取得したデータに応じて、行・単語・音節単位で再生位置を追跡します。
- **歌詞候補の選択・固定**  
  提供元やおすすめ度を確認しながら候補を選択。気に入った歌詞を曲ごとに固定できます。
- **歌詞の編集・行削除**  
  間違った文章を書き換えたり、不要な行を非表示にしたりできます。
- **タイミング補正**  
  曲の好きな位置に補正ポイントを追加し、±20秒の範囲で調整できます。
- **ローカル歌詞の追加・作成**  
  LRCの貼り付け・ファイル読み込みに対応。時刻のない歌詞から同期歌詞を作ることもできます。
- **LRC書き出し**  
  編集した歌詞を、行同期のLRCファイルとして保存できます。
- **バックアップ・データ管理**  
  設定や曲ごとの保存データをバックアップ・復元できます。

## v2.2.2の更新内容

v2.2.1の変更も含みます。

### 標準歌詞がない曲でも「歌詞」を開けるように

YouTube Music標準の歌詞タブが無効な曲でも、外部歌詞の表示・検索画面を開けるようになりました。

外部提供元にも歌詞がない場合は、手動検索やローカル歌詞の追加をご利用ください。

### YouTube Musicに馴染む表示へ

外部歌詞画面の濃い固定背景をなくし、YouTube Musicの背景が見えるようにしました。タブの文字サイズ・書体も標準UIに合わせています。

### タブ切り替えに対応

「次のコンテンツ」「コメント」「関連コンテンツ」への切り替え、またはEscapeキーで外部歌詞画面を閉じられます。

> [!IMPORTANT]
> スマホ版YouTube Musicの歌詞を直接取得する機能ではありません。外部提供元に歌詞がない曲では、自動表示できない場合があります。

## インストール

1. [Releases](https://github.com/taruYDK/ytm-lyrics-sync/releases/latest)から、添付された拡張機能用ZIPをダウンロードします。
2. ZIPを、今後も使用する場所に展開します。
3. ブラウザーの拡張機能管理画面を開きます。
   - Edge：`edge://extensions`
   - Chrome：`chrome://extensions`
4. 「開発者モード」または「デベロッパーモード」を有効にします。
5. 「展開して読み込み」または「パッケージ化されていない拡張機能を読み込む」を選びます。
6. 展開したフォルダーのうち、`manifest.json`が入っているフォルダーを選択します。
7. YouTube Musicのページを再読み込みします。

## 更新方法

1. 拡張機能のポップアップにある「データ保護」から、バックアップJSONを保存します。
2. 新しいバージョンのZIPを展開します。
3. **現在ブラウザーで読み込んでいる拡張フォルダー**に、新版のファイルをすべて上書きします。
4. 拡張機能管理画面で、拡張機能を再読み込みします。
5. 開いているYouTube Musicのページも再読み込みします。

> [!WARNING]
> 更新のために拡張機能を「削除」しないでください。保存データが失われる場合があります。バックアップを取ったうえで、同じフォルダーを上書きして更新してください。

## 基本的な使い方

YouTube Musicで曲を再生し、「歌詞」タブを開きます。

歌詞画面の上部には、次の2つのメニューがあります。

- **歌詞候補**：取得した歌詞の比較・選択・固定
- **その他**：手動検索、歌詞編集、歌詞の追加、LRC保存、診断情報

### 歌詞が違う・見つからないとき

まず「歌詞候補」から別の候補を選んでください。適切な候補がない場合は、「その他 → 手動検索」で曲名やアーティスト名を指定できます。

候補のおすすめ度は、同期方式や曲情報との一致などから計算した目安です。歌詞の正しさを保証するものではなく、ユーザー投票による評価でもありません。

対応する外部提供元：

- Better Lyrics
- LRCLIB
- Unison
- BiniLyrics
- Karalyr

提供元の有効・無効や優先順位は設定から変更できます。

### 気に入った歌詞を固定する

歌詞候補の「📌 この歌詞を固定」を押すと、その動画IDに対して歌詞を保存します。次回以降、同じ動画では固定した歌詞を優先します。

歌詞の優先順位は次のとおりです。

**ローカル歌詞 → 固定した歌詞 → 通常キャッシュ → ネット検索**

ローカル歌詞と固定歌詞は、保存件数を理由に自動削除しません。

### 歌詞の文章を直す・不要な行を消す

「その他 → 歌詞編集」から、文章の修正や不要な行の削除ができます。

編集内容は動画IDと歌詞候補ごとに保存されます。変更した行は、行のタイミングを維持したまま、単語・音節同期から行同期へ切り替わります。

### 歌詞のタイミングを調整する

1. ずれが気になる位置まで曲を再生します。
2. 下部プレイヤーの「歌詞 ±0.0秒」を開きます。
3. 「現在位置に補正ポイントを追加」を押します。
4. ボタンやスライダーで補正値を調整します。
5. 必要に応じて、別の位置にもポイントを追加します。

補正範囲は**±20秒**です。**＋で歌詞が早く、－で遅く**表示されます。

複数のポイントを設定すると、その間の補正量は徐々に変化します。時間順で最後のポイントより後は、その補正値を維持します。

### 自分の歌詞を追加する

「その他 → 歌詞を追加」から、LRCの貼り付けや`.lrc`ファイルの読み込みができます。

保存した歌詞は動画IDごとに端末内へ保存され、外部提供元の歌詞より優先されます。

時刻情報のない歌詞は、同期歌詞作成モードでタイミングを付けられます。歌詞を1行ずつ改行して貼り付け、曲を再生しながら「この行を記録して次へ」を押してください。

### LRCファイルに保存する

「その他 → LRC保存」から、現在の歌詞を行同期LRCとして書き出せます。保存済みの文章修正・行削除も反映されます。

- 単語・音節単位の同期情報は含まれません。
- 曲ごとのタイミング補正を反映するか選択できます。初期状態はOFFです。
- 補正を反映したLRCを同じ曲へ再登録する場合は、二重補正を避けるため、曲の補正を0に戻してください。
- 作成途中の歌詞は、先に保存してください。
- 書き出したファイルが外部サービスへ自動投稿されることはありません。

歌詞を公開・共有する際は、権利者の権利や提供元の利用条件にご注意ください。

### 無操作時に歌詞を自動表示する

設定の「無操作時に歌詞を自動表示」を有効にすると、「次のコンテンツ」の表示中、約2秒間操作がなければ歌詞画面へ移動します。

クリックやスクロールなどの操作をすると、待機時間を数え直します。

## バックアップ・保存データの管理

ポップアップの「データ保護」から、JSON形式でバックアップ・復元できます。

バックアップ対象：

- 表示設定
- 曲ごとのタイミング補正
- 手動検索条件
- 歌詞の編集内容
- 固定した歌詞
- ローカル歌詞

通常の歌詞キャッシュとBetter Lyricsの認証情報は、バックアップに含まれません。

「バックアップ・復元・管理を開く」では、曲名・アーティスト名・動画IDで保存データを検索し、不要な曲のデータを削除できます。

> [!CAUTION]
> 削除した保存データを復元するには、削除前に作成したバックアップが必要です。

## 不具合報告・機能の要望

[GitHub Issues](https://github.com/taruYDK/ytm-lyrics-sync/issues)へお寄せください。

曲固有の不具合では、次の情報を添えていただくと調査しやすくなります。

- 曲名・アーティスト名
- YouTube Musicの動画URL
- 発生した操作と症状
- 「その他 → 診断情報 → 診断情報をコピー」で取得した内容

診断情報には、拡張機能のバージョン、動画ID、提供元、同期方式、候補数などが含まれます。歌詞本文や認証情報は含まれません。

## プライバシー

歌詞の検索時には、曲名・アーティスト名・アルバム名・曲の長さ・動画IDなど、検索に必要な情報を有効な歌詞提供元へ送信します。送信する項目は提供元によって異なります。

自分で追加したローカル歌詞や、編集した歌詞本文は外部へ送信しません。

詳しくは[プライバシーポリシー](PRIVACY.md)をご確認ください。

## 開発

機能別のソースをまとめて、配布用の`content.js`を生成しています。

- `src/content/`：画面表示・検索・保存などの機能別ソース
- `src/core/`：タイミング補間・LRC書き出しなどの処理
- `tests/`：ユニットテスト
- `content.js`：配布用の生成ファイル

Node.js 20以降で実行できます。

```sh
npm run build
npm test
```

ビルドとユニットテストに外部パッケージのインストールは不要です。拡張機能を使うだけなら、Node.jsも必要ありません。

詳しくは[開発ガイド](DEVELOPMENT.md)をご覧ください。
