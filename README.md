# YT Music 歌詞シンクロ

YouTube Music の歌詞タブに、外部の同期歌詞を表示する非公式の Chromium 拡張機能です。

> このプロジェクトは YouTube、Google、Microsoft Edge、および各歌詞提供元とは関係のない非公式プロジェクトです。

## v1.9.8の修正

- 曲名が同じでもアーティストが一致しない候補を拒否し、別人の歌詞が表示される問題を修正しました。
- 英字アーティスト名の姓・名の語順違いや共同アーティスト表記は正しい候補として扱います。
- 再生時間が大きく違う候補を拒否します。
- 以前に保存された誤った歌詞キャッシュを無効化しました。

## 主な機能

- 同期歌詞の自動検索・表示（行／単語／音節同期に対応）
- 曲名・アーティスト・再生時間による誤一致防止
- 複数の歌詞候補からの手動選択とおすすめ度表示
- 曲名・アーティスト名を指定した手動検索
- 歌詞提供元の有効／無効と優先順位の設定
- 曲ごとの歌詞タイミング補正
- 好きな再生位置へ補正ポイントを何個でも追加
- 補正ポイント全削除時の確認ダイアログ
- 補正値・手動検索内容・表示設定のバックアップ／復元
- ZIPの展開先が変わっても同じ拡張機能として扱う固定ID（v1.9.7以降）

## インストール（Edge / Chrome）

1. [Releases](../../releases) から最新版の ZIP をダウンロードして展開します。
2. Edge では `edge://extensions`、Chrome では `chrome://extensions` を開きます。
3. 「開発者モード」をオンにします。
4. 「展開して読み込み」を押し、展開したフォルダ（`manifest.json` が見えるフォルダ）を選びます。
5. YouTube Music を再読み込みします。

### v1.9.6以前からv1.9.7へ更新する場合

固定IDへ切り替わる最初の1回だけ、次の手順で補正値を移します。

1. Releasesにある移行用版 `v1.9.6.1` の中身を、現在Edgeで読み込んでいる旧版フォルダへ上書きします。
2. `edge://extensions` で旧版の「再読み込み」を押します。ここでは「削除」を押さないでください。
3. ポップアップの「データ保護」→「バックアップ・復元を開く」からJSONを保存します。
4. v1.9.7を読み込み、同じ画面からJSONを復元します。
5. YouTube Musicを再読み込みします。

### v1.9.7以降の更新

同じフォルダへ新しい版の中身を上書きし、`edge://extensions` の「再読み込み」を押してください。拡張機能を「削除」するとブラウザが保存データを消すため、更新時は削除しないでください。念のため、更新前に「データ保護」からバックアップできます。

## 使い方

### 歌詞のタイミングを合わせる

下部プレイヤーの「歌詞 ±0.0秒」を開きます。最初の補正欄を調整し、ずれが変わる地点まで再生したら「現在位置に補正ポイントを追加」を押します。以後も必要なだけ追加できます。

### 補正値をバックアップする

拡張機能のポップアップから「データ保護」→「バックアップ・復元を開く」を選びます。書き出したJSONには補正値、手動検索内容、表示設定だけが入り、歌詞キャッシュや認証情報は含まれません。

### 歌詞が見つからない場合

歌詞タブ上部の「手動検索」から、曲名とアーティスト名を入力して再検索できます。同期情報のない通常歌詞だけが存在する場合は、再生位置に合わせられないため表示しません。

## プライバシー

歌詞検索のため、曲名、アーティスト名、アルバム名、再生時間、動画IDを歌詞提供元へ送信します。詳細は [PRIVACY.md](PRIVACY.md) を参照してください。
