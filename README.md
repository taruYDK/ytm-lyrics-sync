# YT Music 歌詞シンクロ v2.0.2

YouTube Musicの歌詞タブに、外部または自分で追加した同期歌詞を表示する非公式のChromium拡張機能です。Microsoft Edge / Google Chromeに対応しています。

> このプロジェクトは、YouTube、Google、Microsoft Edge、および各歌詞提供元とは関係のない非公式プロジェクトです。

[最新版をダウンロード](https://github.com/taruYDK/ytm-lyrics-sync/releases/latest)

## v2.0.2 の修正・改善

### 曲切り替え時の不具合を修正

ローカル歌詞の保存や歌詞候補の固定・解除の処理中に曲が切り替わった場合、処理の完了によって新しい曲の歌詞検索や選択状態が変更されないよう修正しました。

### 保存データの自動削除を廃止

保存曲数が増えると、古いタイミング補正や歌詞編集が自動削除される処理を廃止しました。

これまでの上限は、タイミング補正が500曲、歌詞編集が250曲でした。今回から件数を理由に自動削除しません。

※ 過去に削除されたデータを復元する機能ではありません。

### 同期歌詞作成モードを軽量化

行を記録するたびに一覧全体を作り直していた処理を改善しました。表示要素を再利用し、長い歌詞の記録・取り消し操作で発生する描画負荷を軽減しています。

### 更新について

保存済みの補正・歌詞編集・固定候補・ローカル歌詞は引き継げます。拡張機能を削除せず、現在読み込んでいるフォルダーへ上書きし、拡張機能とYouTube Musicを再読み込みしてください。

## v2.0.0 のアップデート

### この曲ではこの歌詞を固定
- 「歌詞候補」の各候補にある「📌 この歌詞を固定」から、選んだ歌詞を動画IDごとに保存できます。
- 次回は通常キャッシュやネット検索より先に固定した歌詞を表示します。
- 固定を解除すると、その場で通常の候補検索へ戻ります。

### ローカル歌詞を追加
- 「歌詞を追加」から、LRCの貼り付けと `.lrc` ファイルの読み込みができます。
- 保存した歌詞は動画IDごとに端末内へ保存され、すべての外部提供元より優先されます。
- 保存済みのローカル歌詞は確認後に削除でき、削除すると固定候補または通常検索へ戻ります。

### 同期歌詞作成モード
- 時刻のない歌詞を1行ずつ貼り付け、曲を再生しながら「この行を記録して次へ」を押すとLRC時刻を作成できます。
- 「1行戻す」「記録をやり直す」「曲の先頭へ」に対応しています。
- 前の行より前の時刻や、途中で別の曲へ切り替わった状態では誤保存しません。

### 診断情報
- 歌詞画面に、状態・曲ID・提供元・同期方式・候補数を小さく表示します。
- 「診断情報をコピー」で、拡張機能の版、補正ポイント数、プレイヤー時刻の取得元などをコピーできます。
- 診断情報には歌詞本文や認証情報を含めません。

### 保存と優先順位
- 優先順位は `ローカル歌詞 → 固定した歌詞 → 通常キャッシュ → ネット検索` です。
- 固定歌詞とローカル歌詞は、従来の補正・歌詞編集と同様にバックアップ／復元できます。
- 固定歌詞とローカル歌詞は件数で自動削除せず、保存に失敗した場合は入力画面を閉じずにエラーを表示します。
- v1.9.11までに保存した補正・検索条件・歌詞編集はそのまま引き継がれます。

3. 追加された時刻の補正値を調整します。別の場所でも同じ操作を繰り返せます。

1. 下部プレイヤーの「歌詞 ±0.0秒」をクリックします。

4. 途中の補正量は自動計算されます。＋で歌詞が早く、−で遅く表示されます。

## インストール（Edge / Chrome）

1. [Releases](../../releases) から最新版のZIPをダウンロードして展開します。
2. Edgeでは `edge://extensions`、Chromeでは `chrome://extensions` を開きます。
3. 「開発者モード」をオンにします。
4. 「展開して読み込み」を押し、`manifest.json` がある展開先フォルダを選びます。
5. YouTube Musicを再読み込みします。

## v1.9.7以降からの更新方法

1. 念のため、ポップアップの「データ保護」からバックアップJSONを作成します。
2. 新しいZIPを展開します。
3. 拡張機能を削除せず、現在Edge/Chromeで読み込んでいるフォルダの中身を新版ファイルで上書きします。
4. `edge://extensions` または `chrome://extensions` で拡張機能の「再読み込み」を押します。
5. YouTube Musicのタブを `Ctrl+R` で再読み込みします。

固定の拡張機能IDと同じ保存キーを維持しているため、この方法なら補正値、歌詞編集、固定候補、ローカル歌詞を引き継げます。拡張機能を「削除」するとブラウザがローカルデータを消すため、更新では削除しないでください。

## 主な使い方

- 歌詞を固定：歌詞タブ上部の「歌詞候補」から候補を選び、「📌 この歌詞を固定」を押します。
- ローカルLRC：「歌詞を追加」から時刻付きLRCを貼り付けるか、`.lrc` ファイルを読み込みます。
- 同期歌詞を作成：時刻のない歌詞を貼り付け、「♪ 同期歌詞作成モード」で歌い始めごとに記録ボタンを押します。
- 歌詞を書き換え・削除：「歌詞編集」で文章を直すか、不要な行を削除します。
- タイミング補正：下部プレイヤーの「歌詞 ±0.0秒」から、必要な再生位置へ補正ポイントを追加します。
- 不具合調査：「診断情報をコピー」で取得した内容をIssueへ貼り付けます。

## バックアップ

ポップアップの「データ保護」から、表示設定、曲ごとの補正、手動検索条件、歌詞編集、固定候補、ローカル歌詞をJSONへ書き出し・復元できます。通常取得した歌詞キャッシュやBetter Lyricsの認証情報は含めません。

## プライバシー

歌詞検索のため、曲名、アーティスト名、アルバム名、再生時間、動画IDを有効にした歌詞提供元へ送信します。自分で追加したローカル歌詞や書き換えた歌詞は外部へ送信しません。詳細は [PRIVACY.md](PRIVACY.md) を参照してください。
