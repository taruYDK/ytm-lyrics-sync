# YT Music 歌詞シンクロ v2.5.6

YouTube Musicに外部提供元または自分で追加した同期歌詞を表示する非公式のChromium拡張機能です。Edge / Chrome向けです。YouTube・Google・Microsoftおよび各歌詞提供元とは関係ありません。

## 追跡と同期の調整

- **追跡位置**：拡張機能の設定 → 歌詞追跡 → 追跡位置。上から25〜65%、標準42%。冒頭の位置は従来通りです。
- **追跡に戻るまで**：手動スクロール後、1・2・3.5・5・10秒で現在行へ戻ります。標準3.5秒。
- **画面サイズ変更**：歌詞領域のサイズが変わると設定位置へ合わせます。手動閲覧中は設定した待ち時間を優先します。
- **同期ずれ**：再生バーの「歌詞 ±○秒」から「歌詞を0.1秒早く／遅く」を押します。曲全体を調整して保存し、途中補正の差は維持します。±20秒に達した方向は操作できません。
- 追跡位置・復帰時間は操作が止まって500ミリ秒後にまとめて保存します。トグル・文字サイズ・追跡アニメーション・提供元の設定は即時保存です。「保存しました」の表示をご確認ください。

## 読み仮名

設定 →「読み仮名」で、漢字のひらがなと英語のカタカナ読みを別々にON/OFFできます。初期状態では両方ONです。例：今日（きょう）、Hello（ハロー）、love（ラブ）、night（ナイト）。

辞書は同梱しており、歌詞を読み仮名のサービスへ送信しません。日本語辞書を初めて使うときは準備に時間がかかる場合があります。辞書同梱のため配布サイズは以前より大きくなっています。

読みは自動判定です。英語はカタカナで表した発音の目安で、歌唱時の音のつながり・固有名詞・同じ綴りの別発音・歌詞独自の読みは正確に扱えない場合があります。辞書にない語には読みを付けません。4,000文字を超える行では負荷を避けて読みを省略します。「その他」→「ふりがな編集」で行ごとに読みを修正できます。手動読みは保存データ管理・削除・バックアップ・復元の対象です。

読み仮名も本文と連動して追跡します。単語・音節同期では同じ進捗で色が進み、行同期では現在行の読みを明るく表示します。

読み仮名は表示専用です。歌詞本文、同期の時刻、編集内容、LRC出力には混ぜません。単語同期の途中で1つの単語が分割されている場合、読みも対応する表示片へ分けます。

## その他の機能

歌詞候補固定、ローカルLRC追加、同期歌詞作成、歌詞編集、LRC書き出し、曲別補正ポイント、提供元選択、診断情報、バックアップ・保存データ管理に対応します。

## 最新の改善

保存回数の抑制、補正上限の表示、通信待ち時間の上限、復元データの内容検証を追加しました。不正なバックアップは書き込み前に拒否します。旧形式の数値補正も復元できます。

詳しい変更履歴は [CHANGELOG.md](CHANGELOG.md) に統合しました。

## インストール（Edge / Chrome）

1. 配布された最新版のZIPを展開します。
2. Edgeでは `edge://extensions`、Chromeでは `chrome://extensions` を開きます。
3. 「開発者モード」をオンにします。
4. 「展開して読み込み」を押し、`manifest.json` がある展開先フォルダを選びます。
5. YouTube Musicを再読み込みします。

## 更新方法

1. 念のため、ポップアップの「データ保護」からバックアップJSONを作成します。
2. 新しいZIPを展開します。
3. 拡張機能を削除せず、現在Edge/Chromeで読み込んでいるフォルダの中身を新版ファイルで上書きします。
4. `edge://extensions` または `chrome://extensions` で拡張機能の「再読み込み」を押します。
5. YouTube Musicのタブを `Ctrl+R` で再読み込みします。

固定の拡張機能IDと同じ保存キーを維持しているため、この方法なら補正値、歌詞編集、固定候補、ローカル歌詞を引き継げます。拡張機能を「削除」するとブラウザがローカルデータを消すため、更新では削除しないでください。

## 主な使い方

- 歌詞を固定：歌詞タブ上部の「歌詞候補」から候補を選び、「📌 この歌詞を固定」を押します。
- ローカルLRC：「歌詞を追加」から時刻付きLRCを貼り付けるか、`.lrc` ファイルを読み込みます。
- 同期歌詞を作成：時刻のない歌詞を貼り付け、「♪ 同期歌詞作成モード」で歌い始めごとに記録ボタンを押します。
- 歌詞を書き換え・削除：「歌詞編集」で文章を直すか、不要な行を削除します。
- タイミング補正：下部プレイヤーの「歌詞 ±0.0秒」から、必要な再生位置へ補正ポイントを追加します。
- 不具合調査：「診断情報をコピー」で取得した内容をIssueへ貼り付けます。

## バックアップ

ポップアップの「データ保護」から、表示設定、曲ごとの補正、手動検索条件、歌詞編集、固定候補、ローカル歌詞、手動ふりがなをJSONへ書き出し・復元できます。通常取得した歌詞キャッシュやBetter Lyricsの認証情報は含めません。

## プライバシー

歌詞検索のため、曲名、アーティスト名、アルバム名、再生時間、動画IDを有効にした歌詞提供元へ送信します。自分で追加したローカル歌詞や書き換えた歌詞は外部へ送信しません。詳細は [PRIVACY.md](PRIVACY.md) を参照してください。
